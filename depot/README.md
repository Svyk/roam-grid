# Depot submission staging

`extensions/Svyk/roam-grid.json` here is a **draft**. It is not the published
Depot entry and this directory is not read by anything at runtime.

Submitting means forking `Roam-Research/roam-depot`, copying that file to
`extensions/Svyk/roam-grid.json` in the fork with `source_commit` replaced by the
real release commit SHA, and opening a pull request.

That pull request has **not** been opened. The pre-submission checklist, and the
exact step that remains untaken, are in [`../docs/DEVELOPMENT.md`](../docs/DEVELOPMENT.md).
